# Three-minute demonstration script

Prepare one freshly generated DRAFT, its manifest, the run log and the four outputs. Hide `.env`, private receipts, mail addresses, tokens and account settings. Use SAMPLE DATA on screen throughout. Do not narrate mocked or replayed requests as live service evidence.

**0:00–0:25 — Business problem.** “Advertising efficiency alone can hide weaker sales or poor contribution. This PoC brings Python-calculated economics, inventory context and review evidence together. Real LEGO catalog identities are used for familiarity; all retailer performance is simulated.”

**0:25–0:50 — Run and runtime evidence.** Run `./Start-Report.ps1` or show its freshly completed terminal output. Open the HTML and point to its DRAFT/SAMPLE labels, report period and run ID. Show the matching real UTC run-log entry. State whether this run used templates or accepted AI. Execution seconds are machine processing time, not time saved.

**0:50–1:25 — Economics and rules.** Show portfolio spend, net revenue, contribution and TACoS. Open one high-severity product and trace its observed values and threshold. Contrast the efficiency-illusion case with its falling sales and impressions. Explain that the nine rules ask for investigation rather than changing bids, prices or listings.

**1:25–1:50 — Commentary guard.** Show the note label/reason. Explain product/week/metric/unit/direction binding and visible fallback. If demonstrating the hallucination test, label it a test. Say that unknown cause, target and review date remain unknown; the guard does not prove a causal explanation.

**1:50–2:20 — Human gate.** Show `inspect` and its manifest, then describe the explicit owner approval. If a genuine Environment waiting state exists, display it. Otherwise say “The local approval controls are tested; the hosted gate is configured but account access currently blocks its demonstration.” Do not issue approval on the owner's behalf for the recording. After real approval, show that the draft is preserved and the approved manifest differs.

**2:20–2:40 — Flexible outputs/delivery.** Open Excel's six sheets, the PDF and the five-slide deck. The same persisted financial facts feed each. Show both actual received notifications only if available; otherwise identify the implemented adapters and pending real receipt check. Provider acknowledgements are distinct from receipts.

**2:40–3:00 — Honest value proposition and limits.** “This demonstrates repeatable analysis and a reviewable process. It does not claim actual LEGO results or measured savings yet. The next evidence is owner-timed review, verified channel receipts and a real scheduled run. There is no live Amazon API or automatic commercial action.” Show the owner checklist and independent audit handoff.
