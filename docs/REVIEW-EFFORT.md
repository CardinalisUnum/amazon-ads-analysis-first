# Measure review effort

No human time saving has been measured yet. Automated runtime is not review effort or business impact.

Use the same sample period and ten products for both exercises. State that the financial data are simulated. In the manual exercise, use the source inputs and written formulas/rules; in the assisted exercise, use the generated report. Answer the same questions: portfolio economics, the six priority products, evidence for each selected flag, undefined values and investigation items to discuss with the Ads manager.

Time active analysis/review with a stopwatch. Stop for unrelated interruptions and record the exclusions. Include checking the generated commentary and frozen identity in assisted review; report download/setup time separately. If repeating the exercise, change the product order or use another seed and disclose learning effects. One person's sample benchmark is not a general productivity study.
